# Hytera-CPS-extractors-and-conversions
Extractors/decoders for Hytera RCDX and RCD v9.x.i . It should work with the following:

## Probable supported models

Portable Handheld Radios

    BD Series (Business Digital): BD302, BD362, BD502, BD552, BD612

    PD4 / PD5 Series (Entry Commercial): PD402, PD412, PD482, PD502, PD562

    PD6 Series (Slim / Compact): PD602, PD662, PD682

    PD7 Series (Heavy Duty): PD702, PD752, PD782, PD792

    PD9 Series (Flagship): PD982

    X1 Series (Ultra-Slim Covert): X1e, X1p

Mobile (Vehicle / Base) Radios

    MD6 Series: MD652 (and MD652G with GPS)

    MD7 Series: MD782 (and MD782G with GPS)

Repeaters

    RD Series: RD622, RD962, RD982
